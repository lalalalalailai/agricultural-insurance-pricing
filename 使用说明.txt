================================================================
  农险期货智能定价系统 - 使用说明
  乡村振兴背景下基于因果推断的农险期货定价模型
================================================================

一、系统环境要求
----------------------------------------------------------------
  • Python 3.10 或更高版本
  • 操作系统: Windows 10/11 (推荐), Linux, macOS
  • 内存: 8GB 以上 (推荐16GB)
  • 磁盘空间: 500MB 以上

二、安装步骤
----------------------------------------------------------------
  1. 解压本压缩包到任意目录
  2. 打开命令行终端 (CMD/PowerShell)
  3. 进入 src 目录:
     cd src
  4. 安装依赖:
     pip install -r ..\requirements.txt

三、启动系统
----------------------------------------------------------------
  方式1 (推荐): 使用一键启动器
     双击 一键启动.bat
     或在命令行运行: python src/launcher.py

  方式2: 手动启动
     cd src
     streamlit run app.py --server.port 8501

  启动成功后, 浏览器自动打开 http://localhost:8501

四、系统功能模块
----------------------------------------------------------------
  系统包含12个功能Tab:

  Tab1 - 数据探索:
    • 36品种期货数据加载与可视化
    • 统计摘要、价格走势图、数据预览
    • 数据质量自动验证(5维检查)

  Tab2 - 因果分析:
    • Agri-PC时序因果发现(三重约束)
    • 五重因果效应估计: PSM / S-Learner / T-Learner / DML / IV
    • 因果DAG可视化
    • 五重验证共识分析

  Tab3 - 定价模型:
    • XGBoost双轨定价: 基准价格 + 因果风险溢价
    • 模型性能指标展示
    • SHAP可解释性分析(Summary+Waterfall)
    • 纯预测验证(无lag特征)
    • Bootstrap不确定性量化(95%置信区间)

  Tab4 - 风险评估:
    • 风险因子识别与排序
    • 情景分析与压力测试

  Tab5 - 报告生成:
    • 自动生成Markdown格式研究报告
    • 包含完整分析结果与图表

  Tab6 - 原创算法:
    • Agri-PC: 农险时序因果发现算法(三重约束)
    • ACML: 农业异质性因果定价元学习器
    • CCP: 因果保形预测定价框架
    • 六大定理验证

  Tab7-12 - 扩展功能:
    • 数据集总览 / 研究报告 / 社会价值
    • 保费厘定 / 风险预警 / 政策评估

五、操作流程
----------------------------------------------------------------
  1. 在左侧选择品种(如"豆一")和时间范围
  2. 点击"数据探索"查看数据概况与质量验证
  3. 点击"因果分析"运行因果发现与效应估计
  4. 点击"定价模型"训练XGBoost模型并查看SHAP解释
  5. 点击"风险评估"查看风险分析结果
  6. 点击"报告生成"导出研究报告
  7. 点击"原创算法"运行三大原创算法

七、原创算法说明
----------------------------------------------------------------
  算法1 - Agri-PC (农险时序因果发现):
    三重约束: 时序因果 + 农业生长周期 + 期货交割
    定理1: 因果识别充分条件
    定理2: 约束结构一致性

  算法2 - ACML (农业异质性因果定价元学习器):
    三项创新: 风险正则 + 交割权重 + 双重正交化
    定理3: CATE√n一致性
    定理4: 因果无偏风险溢价

  算法3 - CCP (因果保形预测定价框架):
    三项创新: 因果残差 + 时序自适应 + 分位数回归
    定理5: 有限样本覆盖保证
    定理6: 因果残差保形有效性

八、常见问题
----------------------------------------------------------------
  Q: 启动时提示端口被占用?
  A: 修改端口号: streamlit run app.py --server.port 8502

  Q: 数据加载失败?
  A: 检查 data 目录是否在项目根目录下

  Q: 依赖安装失败?
  A: 使用国内镜像: pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
