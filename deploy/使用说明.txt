================================================================
  农险期货智能定价系统 - 使用说明 (Docker部署版)
  乡村振兴背景下基于因果推断的农险期货定价模型
================================================================

一、系统环境要求
----------------------------------------------------------------
  • Docker 20.10+ 和 Docker Compose 2.0+
  • 内存: 8GB 以上 (推荐16GB)
  • 磁盘空间: 2GB 以上

二、Docker部署步骤
----------------------------------------------------------------
  1. 解压本压缩包到任意目录
  2. 打开命令行终端
  3. 进入项目目录:
     cd 03_源码及说明
  4. 构建并启动容器:
     docker-compose up -d --build

三、访问系统
----------------------------------------------------------------
  启动成功后, 浏览器访问 http://localhost:8501

四、系统功能模块
----------------------------------------------------------------
  系统包含12个功能Tab:

  Tab1 - 数据探索:
    • 36品种期货数据加载与可视化
    • 统计摘要、价格走势图、数据预览
    • 数据质量自动验证(5维检查)

  Tab2 - 因果分析:
    • Agri-PC时序因果发现(三重约束)
    • 五重因果效应估计: PSM / S-Learner / T-Learner / DML / IV
    • 因果DAG可视化
    • 五重验证共识分析

  Tab3 - 定价模型:
    • XGBoost双轨定价: 基准价格 + 因果风险溢价
    • SHAP可解释性分析(Summary+Waterfall)
    • 纯预测验证(无lag特征)
    • Bootstrap不确定性量化(95%置信区间)

  Tab4 - 风险评估:
    • 风险因子识别与排序
    • 情景分析与压力测试

  Tab5 - 报告生成:
    • 自动生成Markdown格式研究报告

  Tab6 - 原创算法:
    • Agri-PC / ACML / CCP 三大原创算法
    • 六大定理验证

  Tab7-12 - 扩展功能:
    • 数据集总览 / 研究报告 / 社会价值
    • 保费厘定 / 风险预警 / 政策评估

五、常见问题
----------------------------------------------------------------
  Q: 端口被占用?
  A: 修改 docker-compose.yml 中的端口映射

  Q: 数据加载失败?
  A: 检查 data 目录是否在项目根目录下

  Q: 依赖安装失败?
  A: Docker构建时自动使用国内镜像源
